# L8 数据复盘与下一轮开发

## 进入条件

满足以下任一条件：完成 20-50 家客户开发、一轮发送与跟进、已有足够真实回复，或出现完整询价/样品/订单案例。

## 复盘表

比较实际记录，而不是回忆印象：

| 维度 | 本轮记录 | 下一步判断 |
|---|---|---|
| 市场/地区 |  | 继续、修改或停止测试 |
| 客户类型/应用 |  |  |
| 找客来源 |  |  |
| 产品卖点/证明 |  |  |
| 开发信版本 |  |  |
| 回复和异议 |  |  |
| 发送与回复数量 |  |  |
| 失败或未处理项 |  |  |

把“发生了什么”和“为什么发生”分开。小样本只能形成 `observation` 或 `hypothesis`，不能写成“这个市场一定有效”。

## 交付

输出一份短复盘和一个下一轮测试：只改变一个主要变量，例如客户类型、应用关键词、证明材料或开场角度。不要用增加发送数量掩盖名单和匹配问题。

## 完成证据

用户确认下一轮测试变量、样本范围和记录字段，并更新进度卡。若证据不足，明确写“暂不能判断”。
