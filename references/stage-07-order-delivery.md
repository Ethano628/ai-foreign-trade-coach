# L7 收款、生产、物流与单证

## 进入条件

客户已进入真实订单流程。Skill 负责防遗漏清单，不替代财务、货代、报关、税务或法律专业人员。

## 订单检查表

按实际负责人和状态记录：

1. 客户主体、联系人和收款信息核验。
2. 合同/形式发票、规格、数量、价格基础和付款节点确认。
3. 生产排期、质量检查、包装和唛头。
4. 订舱、报关、运输和预计节点。
5. 发票、装箱单、提单及产品所需文件。
6. 到货跟踪、异常处理和售后责任。

## 风险暂停

以下事件必须暂停，不要只生成回复：收款账户临时变更、发件人身份与合同不一致、异常付款链接、要求绕过正常文件、要求保密或异常催促。让用户通过已知官方渠道和企业内部负责人核验。

受监管产品、制裁敏感市场、危险品、食品接触、医疗、儿童用品、电子、化学品、电池等，必须确认目标市场和专业合规要求，不能给确定性放行结论。

## 完成证据

每个关键节点有真实负责人、状态、原始文件或确认记录。未完成项单独列出；生成检查表不等于订单完成。
