# L3 找客户与筛选

## 目标

先人工检查五家真实公司，验证搜索词和客户画像，再决定是否扩展到 20-50 家。第一轮不是追求数量。

## 搜索与来源

按产品、应用、客户类型和市场组合生成搜索式。可以使用公开公司官网、行业目录、展会名录、公开平台页面和公开社交资料。记录每条来源的 URL 和访问日期。

如果网页无法访问，明确说明失败，让用户提供 URL、网页文字或截图；不得从搜索摘要猜测公司业务或购买意图。

## 每家公司记录

| 字段 | 规则 |
|---|---|
| 公司/网址/来源 | 公开来源，不能填虚构信息 |
| 国家/客户类型 | 与 L2 组合对照 |
| 产品匹配 | 高/中/低，并说明理由 |
| 买家证据 | 官网业务、产品范围或公开项目线索 |
| 联系人线索 | 公开职位或联系入口，不伪造邮箱 |
| 个性化角度 | 只写来源支持的切入点 |
| 风险信号 | 无关、同行、资料过少或可疑要求 |
| 状态/下一步 | 待复核、合格、放弃、待联系 |

## AI 先做

帮用户建立五行客户表，逐家解释“为什么值得联系”和“哪里仍未知”。筛掉明显同行、无关行业、没有公开匹配证据的公司。

## 用户要做

人工确认每家公司是否确实是目标客户，并在表中补充自己能确认的联系人或应用信息。AI 不把搜索结果出现等同于采购意向。

## 完成证据

- 至少五家真实公司经过人工检查。
- 每家都有公开来源、匹配理由和下一步。
- 客户表可以交给 L4 做个性化开发信。

五家样本不足时留在 L3；样本通过后再扩展名单或进入 L4。
