# 外贸进度卡

用这张卡在每个关键动作后记录可验证状态。卡片可以直接粘贴到新对话中继续。

```markdown
# 外贸进度卡

- 企业/身份：
- 当前主推产品：
- 当前等级：
- 原主线等级：
- 本轮目标：
- 已确认事实：
- 尚未确认：
- 已完成动作：
- 完成证据：
- 已生成资料：
- 当前客户事件：
- 眼前唯一任务：
- 完成后进入：
- 最后更新日期：
```

## 使用规则

- 当前等级只能由完成证据推动，生成模板不算执行完成。
- `原主线等级`用于记录 L5-L7 临时客户事件处理前的主线位置。
- 已确认事实、完成证据和已完成动作要追加保留，不用后续猜测覆盖。
- 不记录密码、验证码、银行卡、身份证件、完整支付凭据或其他敏感身份/财务数据。
- 同一对话直接更新；换对话时用户贴回卡片即可恢复。
- 是否保存为本地文件由用户决定，保存前先征得同意。
- 部分完成要分别标记完成、失败和未处理项。

## 每次更新的最小格式

```markdown
本轮完成：
- 动作：
- 证据：
- 仍未完成：
- 下一步唯一任务：
- 预计进入：
```
