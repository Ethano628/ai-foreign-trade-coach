## First Outreach Email

```markdown
Subject: {specific product/application benefit}

Hi {Name/Team},

I found {company} while researching {market/application/customer type}. It looks like you work with {relevant product/application/channel}.

We are a manufacturer of {product} in {location if useful}. For buyers like you, we may be helpful because:

- {specific advantage 1}
- {specific advantage 2}
- {proof asset or capability}

Would it be useful if I send a short catalog / sample specs / quotation reference for {specific product or application}?

Best regards,
{Name}
```

## Follow-up Sequence

```markdown
Follow-up 1:

Hi {Name/Team},

Just following up on my note about {product/application}. If {company} is currently sourcing or comparing suppliers for {use case}, I can send {catalog/spec/sample/pricing reference}.

Would you be the right person to contact?

Best,
{Name}

Follow-up 2:

Hi {Name/Team},

I do not want to bother you if this is not relevant. Before I close my note, could you let me know whether {product/application} is something your team handles?

If not, no problem.

Best,
{Name}
```

## Reply Handling

```markdown
If they ask for price:
- Confirm specifications.
- Ask quantity, destination, packaging, certificate needs, customization, deadline.
- Explain quote basis.

If they ask for catalog:
- Send catalog plus 2–3 recommended models.
- Ask what application or customer group they serve.

If they say not interested:
- Thank them.
- Ask if there is a better product category or season.
- Do not push repeatedly.

If no reply:
- Follow up twice, then stop or add to long-term nurture.
```
