# L2 市场与客户画像

## 目标

为一个主推产品选择一个可以测试的市场组合，而不是宣称“全世界都能卖”。

## 组合边界

第一轮只确定：

- 一个优先测试国家或区域。
- 一至两个客户类型，例如进口商、分销商、安装商、工程承包商或使用该产品的制造商。
- 一个主要采购/应用场景。

如果没有当前来源，使用“工作假设”而不是确定性市场结论。把用户事实、公开来源、推断、假设和未知分别写出。

## AI 交付

输出一个简表：

| 项目 | 内容 |
|---|---|
| 产品和应用 |  |
| 优先市场 |  |
| 客户类型 |  |
| 典型买家职位 |  |
| 为什么可能采购 |  |
| 需要什么证明 |  |
| 可能的第一障碍 |  |
| 不合格信号 |  |
| 英文搜索词 |  |
| 证据/未知 |  |

搜索词按“产品 + 应用 + 客户类型 + 国家/城市”组合，避免只搜 `product buyer` 这种宽泛词。

## 用户要做

确认第一轮要测试的“产品 x 市场 x 客户类型”组合。若用户无法选择，只给两个候选并说明选择会改变的后续搜索动作。

## 完成证据

- 用户确认一个测试组合。
- 该组合能直接生成客户搜索式和筛选条件。

完成后进入 L3；如果已有五家真实潜客，则直接检查 L3 证据并可跳到 L4。
